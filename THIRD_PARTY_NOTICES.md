# Créditos e origem dos recursos

## OSLab

O computador Windows deste projeto reutiliza o código e os recursos locais de [FernandoBalbino/OSLab](https://github.com/FernandoBalbino/OSLab), no commit `357a66122f3819b0534e37bb2a20c35e12e9b887`. Autor: Fernando Balbino. A cópia fica em `windows/`; as adaptações acrescentam isolamento por cliente, relógio de atividade, snapshots, atalhos e remoção de aplicativos nas Configurações.

Os avisos originais são preservados em [windows/THIRD_PARTY_NOTICES.md](windows/THIRD_PARTY_NOTICES.md), incluindo as fontes e licenças dos demais recursos incorporados.

- **win11React**, blueedgetechno e colaboradores: ícones e referência visual do Windows, sob CC0-1.0. Licença preservada em `windows/LICENSE-win11React.txt`.
- **Microsoft Fluent UI System Icons**, Microsoft e colaboradores: ícones das ações, sob MIT. Licença preservada em `windows/assets/learning/icons/LICENSE.txt`.
- **Nunito Sans**, The Nunito Sans Project Authors: fonte local, sob SIL Open Font License 1.1. Licença preservada em `windows/assets/fonts/OFL-NunitoSans.txt`.
- As marcas e os logotipos identificam interfaces simuladas; o projeto não é afiliado à Microsoft nem aos fabricantes dos navegadores.

## Referência de design

[Customer Support Dashboard UI Kit](https://www.figma.com/design/6UYQWYigSqjdyGbw7iTF5X/Customer-Support-Dashboard-UI-Kit--Community-), de Silverthread Labs. Consultado como inspiração de paleta, cards, navegação e estados. Nenhuma captura do Figma é utilizada como tela da aplicação.
